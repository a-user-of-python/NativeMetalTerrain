# NativeMetalTerrain

Native iOS 3D terrain app built on Metal 4 (with Metal 3 fallback). No longer a demo — this is the real app.

## Features
- Procedural terrain with continents, mountains, rivers, beaches
- Per-material specular (rock, sand, grass, snow, water)
- Metal 4 / Metal 3 renderer with on-screen badge
- Walk and orbit camera modes
- Adjustable sun, fog, water, structures

## Building
Open `NativeMetalTerrain.xcodeproj` in Xcode and run on a physical iOS device.

## Releases
Unsigned IPAs are built automatically via GitHub Actions and attached to releases. Sideload with Sideloadly or AltStore.
